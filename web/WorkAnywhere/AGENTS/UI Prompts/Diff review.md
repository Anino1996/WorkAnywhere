A premium dark-mode mobile diff viewer for reviewing AI-generated code changes, displayed on a smartphone. Clean, readable, developer-focused.

Full-screen modal style (overlay):

Top bar:
- Title: “Review Changes”
- Left: back arrow
- Right: “Apply” (blue button)

Main content:
- code diff view (mobile optimized)
- unified diff format:
  - removed lines in red with - prefix
  - added lines in green with + prefix
- syntax highlighting (subtle, not noisy)
- monospaced font, high readability
- line numbers optional but minimal

Bottom sticky actions:
- “Reject” (subtle)
- “Apply Changes” (primary blue)

Design:
- dark background (#0b0b0c)
- high contrast code colors
- clean spacing, no visual noise
- no side-by-side (mobile optimized)

Extras:
- small file name header above diff (e.g., “app.py”)

Overall:
- focused, intentional, safe review experience
- encourages careful inspection without overwhelm
