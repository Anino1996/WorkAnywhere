A dark-mode mobile coding assistant interface focused on a clean chat experience, on a modern smartphone. Minimal, distraction-free, highly polished.

Layout structure:

Top: thin workspace bar (collapsed)
- “Dev Server 1 • Python” with small green status dot
- very subtle, low-height, not dominant

Main area: chat thread (primary focus)
- alternating message bubbles:
  - user messages (simple, right-aligned)
  - AI responses (left-aligned, slightly richer)
- AI responses include:
  - short explanation text
  - subtle action chips:
    [ View Changes ]   [ View Logs ]
- no code clutter inline by default

Bottom: action bar (above input)
- small icon buttons:
  ▶ Run    🧪 Test    🔨 Build
- minimal, icon-first, evenly spaced, low visual weight

Bottom-most: input bar
- rounded input field: “Type what you want to build…”
- left: small + button (attachments/tools)
- right: send arrow button

Design:
- deep black background, soft blue highlights
- generous spacing between messages
- smooth, calm, focused aesthetic
- no visible file tree, no clutter
- everything feels conversational and controlled

Lighting:
- subtle glow around active elements
- premium, futuristic but restrained
