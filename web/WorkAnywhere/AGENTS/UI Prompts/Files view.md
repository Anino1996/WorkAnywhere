A clean dark-mode mobile file explorer for a coding workspace.

Layout:
- top bar: “Files”
- simple list view:
  - folders and files with icons
  - names aligned left
  - minimal metadata

No clutter:
- no complex tree expanded by default
- tap to drill down

Design:
- dark background
- subtle separators or none
- focus on readability

Optional:
- floating action button for new file

Overall:
- simple, secondary, not the main experience
